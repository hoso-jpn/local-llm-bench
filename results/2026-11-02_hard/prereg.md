# 事前登録：難しい推論・長い生成・長い文脈

**計測を始める前にこのファイルをコミットする。** 1回目の品質評価（`results/2026-11-01_quality/`）は、どの構成も 97〜100% で天井に当たり、量子化の差が見えなかった。もっと難しい課題で、差が出るかを確かめる。

## 予想

| 課題 | strata-BX（IQ3_XXS） | strata-B（IQ3_S） | freetoken-B（NVFP4） |
| --- | --- | --- | --- |
| AIME | 55〜78% | 60〜80% | 65〜85% |
| MATH-500 レベル5 | 82〜93% | 85〜95% | — |
| 1つ探す（16K〜128K） | 95〜100% | 95〜100% | 95〜100% |
| 似た中から選ぶ | 128K で 75〜95%、32K 以下は 90〜100% | 同程度か少し高い | 同程度か少し高い |
| 参照をたどる | 128K で 50〜85%、32K 以下は 75〜100% | 同程度か少し高い | 同程度か少し高い |
| 打ち切り（AIME） | 5〜20% | 5〜15% | 3〜15% |
| ループ（AIME） | 2〜10% | 1〜8% | 1〜8% |

1. **難しい推論では、量子化が大きいほど正答率が高い傾向が出る（NVFP4 ≥ IQ3_S ≥ IQ3_XXS）。** ただし AIME は 60 問しかなく（信頼区間 ±12 ポイント程度）、差は信頼区間の中に収まる可能性が高い。MATH-500 レベル5（134 問）では IQ3_S と IQ3_XXS の差が 2〜6 ポイント出る
2. **長い生成ほど量子化の影響が積み重なり、小さい量子化ほど打ち切りとループが多い**
3. **長い文脈では、1つ探す課題はどれも満点に近い。差が出るのは、似た中から選ぶ課題と参照をたどる課題で、128K で最も大きい**
4. **長い文脈の速度**：decode は Strata で 30K から 10% 以内しか落ちない（48 層中 36 層が線形 attention のため）。FreeToken は KV キャッシュの分だけ expert のスロットが減り、5〜15% 落ちる。128K の TTFT は Strata 20〜35 秒、FreeToken 50〜120 秒

### わかったこと

1. **量子化の差は、難しい推論で初めて見えた。** 易しい課題（1回目の品質評価）では同じだった IQ3_XXS と IQ3_S が、AIME で 11.6 ポイント離れた（対応のある比較で p = 0.039）。IQ3_S と NVFP4 は AIME で区別できない
2. **差の正体は「考え終わらない」こと。** IQ3_XXS は出力が長く（中央値 14,193 vs 11,588）、上限で打ち切られる問題が 2 倍以上ある。量子化の影響は、答えの誤りより思考の長さに出る
3. **正答1件あたりの時間は Strata IQ3_S が最も短い**（76.5 s）。FreeToken NVFP4 は同じ正答率で 3.8 倍（292.3 s）かかる。IQ3_XXS は生成が速くても、打ち切りで時間を使うため IQ3_S より遅い（91.8 s）
4. **長い文脈は、128K まで 3 構成とも正確に読めた。** 合成した検索課題では差がつかない。差を測るには、もっと難しい長文課題（要約、複数文書の推論など）が要る
5. **長い文脈の速度は入力長にほぼ比例し、decode はほぼ落ちない。** 128K の TTFT は Strata 約 21 秒、FreeToken 45〜53 秒。どちらも線形 attention 層が多いため、decode は 30K からほとんど変わらない

### 限界

- AIME は 60 問で、温度 0 の1回だけ。2026 年の問題もモデルの学習時期によっては見られている可能性がある（2025 年と 2026 年で正答率に大きな差はない）
- 生成上限 32,768 で打ち切ったため、正答率は上限に依存する
- FreeToken では MATH L5 を計測していない（時間の都合。事前登録どおり）
